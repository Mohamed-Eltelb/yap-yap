# Reporting a security issue

Send a private report to the maintainer using the contact email listed on [Mohamed Eltelb’s GitHub profile](https://github.com/Mohamed-Eltelb). If the repository’s Security tab offers **Report a vulnerability**, you can use that private channel instead.

Include the affected version or commit, operating system, the behavior you observed, and its impact. Use synthetic dictation text and redact API keys, recordings, clipboard contents, and local app data. Please keep sensitive details in the private report while the issue is being investigated.
